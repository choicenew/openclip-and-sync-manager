Features

全方位强化的核心功能

告别收费插件与中心化服务器，享受全模态无缝同步体验。

📋

多端剪贴板历史

基于 Offscreen 文档毫秒级捕获复制记录。支持升序/降序灵活调序、敏感词正则清洗、自动去重与分类标签。

  • 自由调序：最新在前 / 最旧在前
  • 过滤敏感 Token 与 Base64 大图
  • 键盘快捷键直接粘贴 (Alt+Shift+1/2/3)
🗂️

Tab Groups 会话管理

原生兼容 Tab Session Manager (TSM)。自动侦测标签组变动，支持启动/关闭自动保存快照及 URL 黑名单。

  • 跨设备一键恢复标签组与窗口
  • 定时自动快照备份与去重
  • 支持屏蔽特定敏感 URL 域名
👑

主辅设备控制流

创新的 Master-Slave 设备控制模型。主设备统一决定云端抓取规则，辅助设备自动变形降级并隔离权限。

  • 云端主设备标记与锁策略
  • 辅助设备自动识别并禁止改权
  • 彻底避免多节点非授权覆盖冲突
Storage Engine

7 大无损云端 Backend 存储

自带云端服务，直连你的私有存储，绝无第三方中间商与隐私风险。

☁️

WebDAV 存储

完美支持坚果云 (Nutstore)、Nextcloud、群晖 NAS 及自建 WebDAV。支持内置 Gzip 高能文本压缩。

🪣

AWS S3 / MinIO

兼容 S3 标准协议的对象存储。支持自定义 Endpoint、Bucket、AccessKey 与 SecretKey 参数卡片。

🐙

GitHub Gist

使用 Personal Access Token (PAT) 与 Gist ID，将剪贴板与会话安全保存在私有 Gist 存储中。

📁

OneDrive & Google Drive

使用微软 Graph API 与 Google OAuth2 原生云盘极速直连备份，随用随存。

🔄

Chrome Sync

利用谷歌账号内置 Sync 服务轻量备份，智能压缩并严格控制在 8KB 单项存储限制内。

🔌

Custom REST API

支持配置自定义 HTTP/HTTPS 端点，方便开发者无缝对接企业内部自建 REST 服务。

Open Source & Build

代码 100% 开源，欢迎所有人编译与修改

项目使用 Modern TypeScript + React 18 + Plasmo MV3 架构构建。你可以随意 fork、修改并提交代码！

bash — openclip-and-sync-manager
# 1. 克隆 GitHub 官方源代码仓库
$ git clone https://github.com/choicenew/openclip-and-sync-manager.git
$ cd openclip-and-sync-manager

# 2. 安装项目依赖
$ pnpm install

# 3. 启动开发调试模式 (支持热重载)
$ pnpm dev

# 4. 打包生成 Production 生产构建产物
$ pnpm build
