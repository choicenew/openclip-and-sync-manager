Competitive Matrix

维度的比拼：为什么选择 OpenClip Sync？

打破传统扩展的收费门槛与中心化数据风险，用去中心化架构重新定义多端同步。

对比维度 / 功能 ✨ OpenClip Sync (本扩展) 传统剪贴板扩展 传统 Tab Session Manager
收费与授权模式 ✓ 100% 永久免费开源 (MIT) ✗ 限制历史条数，开启云同步需 Pro 订阅 ($5/月) ✗ 部分高级存储受限或需额外赞助
云端存储后端 ✓ 直连 7 大私有云 (WebDAV/S3/Gist/Drive/REST) ✗ 强制使用官方第三方服务器 (风险未知) ✗ 仅支持基本存储或本地导出的 JSON
全模态浏览器数据 ✓ 剪贴板 + 标签组 + 书签 + 历史 + 扩展清单 ✗ 仅支持文本/图片剪贴板 ✗ 仅支持标签页会话组
多节点冲突与控权 ✓ 👑 主辅设备墙控制流 (自动降级与云锁) ✗ 无主辅概念，多设备并发同步极易相互覆盖 ✗ 无云端锁机制，容易导致会话覆盖丢失
内存与性能开销 ✓ 极低 (MV3 Offscreen + Base64 滤重优化) ✗ 大图容易引发 V8 Heap 内存暴涨崩溃 ✗ 标签页过多时恢复延迟严重
数据隐私与安全性 ✓ 100% 私有端到端传输，无任何中间服务器 ✗ 敏感数据经由第三方中转云端 ✓ 偏向本地或受限云端
Full Spectrum Modules

彻底覆盖浏览器全模态数据

我们构建了完整的功能矩阵，一个扩展即可替代 5 个单一功能的扩展。

📋

多端剪贴板历史

基于 MV3 Offscreen 离线静默抓取，支持升降序任意调序、正则表达式敏感词清洗、自定义标签与快捷键一键粘贴 (Alt+Shift+1/2/3)。

  • 自由正序/倒序排列显示
  • 屏蔽密码、Token 与 Base64 大图
  • 快捷置顶与自定义标签归类
🗂️

Tab Groups 会话管理

原生对标 Tab Session Manager (TSM)。自动抓取 Chrome/Edge 标签组，启动/关闭自动快照备份，支持根据域名黑名单屏蔽敏感 Tab。

  • 自动定时备份与去重
  • 跨设备一键恢复标签组与窗口
  • 支持导出格式与备份历史恢复
🔖

跨设备书签树同步

次级页面支持跨浏览器书签树读取与云端双向同步，智能合并重复条目，并支持在 Popup 中快速检索打开。

  • 跨系统与跨浏览器书签合并
  • 拼音/关键词秒级全文搜索
  • 无感后台增量更新
📜

30 天浏览历史云备份

自动将跨设备浏览历史进行结构化多云同步，保留 30 天历史痕迹，随时在任何设备查找先前看过的网页。

  • 跨设备时间线整合
  • 域名频率分析与快捷定位
  • 支持敏感域名排除记录
🧩

已安装扩展清单备份

一键备份所有已安装浏览器扩展清单，重装系统或切换新设备时可一键跳转 Chrome Web Store 快速恢复安装。

  • 导出扩展列表清单 JSON
  • 直达官方 Web Store 安装页
  • 记录各设备扩展配置快照
👑

主辅设备墙控制流

创新的云端主设备锁机制。主设备掌握规则控制权，辅助设备自动识别云端标记并降级限制，防止跨设备抢权。

  • 设备注册表与活跃卡片墙
  • 辅助设备自动降级变形
  • 云端权限隔离防止数据覆盖
Storage Engine

7 大无损私有云 Backend 存储

自带云端服务，直接连接你的私有存储，绝无第三方中间商与隐私泄露风险。

☁️

WebDAV 存储

支持坚果云 (Nutstore)、Nextcloud、群晖 NAS 及自建 WebDAV，内置 Gzip 文本高能压缩。

🪣

AWS S3 / MinIO

支持自建 MinIO 或 AWS S3 对象存储，配置 Custom Endpoint, Bucket, AccessKey/SecretKey 卡片。

🐙

GitHub Gist

使用 Personal Access Token (PAT) 与 Gist ID，将剪贴板与会话安全备份在私有 Gist 中。

📁

OneDrive & Google Drive

微软 Graph API 与 Google OAuth2 原生云盘直连，无感后台同步。

🔄

Chrome Sync

谷歌账号内置轻量服务同步，智能压缩控制在单项 8KB 上限内。

🔌

Custom REST API

支持配置自定义 HTTP/HTTPS 端点，无缝对接企业自建 REST 服务。

Open Source & Build

代码 100% 开源，欢迎所有人编译与修改

基于 Modern TypeScript + React 18 + Plasmo MV3 架构。你可以随意 fork、修改并提交 Pull Request！

bash — openclip-and-sync-manager
# 1. 克隆 GitHub 官方源代码仓库
$ git clone https://github.com/choicenew/openclip-and-sync-manager.git
$ cd openclip-and-sync-manager

# 2. 安装项目依赖
$ pnpm install

# 3. 启动开发调试模式 (支持热重载)
$ pnpm dev

# 4. 打包生成 Production 生产构建产物
$ pnpm build
