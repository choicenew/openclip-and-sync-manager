🚀 去中心化多端数据同步 Chrome / Firefox 扩展

更快、更安全的全模态浏览器数据与剪贴板同步工具

完全掌控属于你自己的私有数据。支持剪贴板历史、书签树、Tab Groups 会话组与浏览历史的私有多云同步。

📥 下载扩展安装包 (Releases) ⭐ GitHub 源代码

全方位强化功能

📋

多端剪贴板历史

实时监控剪贴板，支持正序/倒序自由排序、敏感词自动清洗、关键词黑名单过滤与标签分类。

🌐

Tab Groups 会话管理 (TSM)

原生对标 Tab Session Manager，支持自动快照保存、按会话恢复标签组、URL 黑名单过滤与名称模板。

👑

主辅设备控制流

创新 Master-Slave 架构，主设备一键授权，辅助设备自动限制，防止跨节点非授权拉取。

支持的全模态同步后端

☁️

WebDAV (坚果云 / Nextcloud)

私有网盘支持，智能 Gzip 文本高能压缩，多设备无缝同步。

🔒

GitHub Gist & AWS S3 / MinIO

支持使用 GitHub PAT 私有 Gist 或 S3/MinIO 对象存储作为去中心化同步后端。

⚡

Chrome Sync / OneDrive / Google Drive

全面兼容各大原生云盘与云服务，数据直连，无任何第三方中间商。
